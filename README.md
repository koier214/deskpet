

基于 PySide6 的极简桌面宠物「一二」：常驻桌面，头顶挂待办气泡，自动统计陪伴时长，
并可用账号和另一台电脑上的「布布」聊天。

## 运行

Windows 用户：**双击 `启动桌宠.bat`**，首次运行会自动安装依赖，之后直接启动（没有 cmd 黑窗口）。

也可以在命令行手动跑：

```powershell
pip install -r requirements.txt
python main.py
```
要求 **Python 3.10 以上**。依赖为 PySide6（窗口与 WebSocket）和 zxing-cpp（本地二维码解码）；
运行 `pip install -r requirements.txt` 即可安装。

## 功能

- **待办**：日历选日期 + 按天分组，每条待办可挂倒计时；「今天 / 顺延 / 其他任务」三个入口，
  日历上有未到期棕 / 已顺延红 / 已完成灰三态标记，顺延能单条或批量「移到今天」。
- **固定任务**：可以建「每天 / 每个工作日」的规则，命中的日子自动往当天待办追加一条。
- **头顶气泡**：无边框悬浮窗，显示待办、已完成任务和收到的聊天消息。
- **聊天**：账号模式（手机号注册/登录 + 连接码配对），消息按会话分开，带在线状态与历史记录。
- **陪伴统计**：桌宠开了多久（今天 / 本次 / 最近 7 天 / 累计）。
- **二维码扫描**：Windows 上可在任何软件里按 **Alt+Q**，或从右键菜单启动，框选屏幕上的二维码。
  支持多屏和不同缩放比例；识别到网址后显示结果，3 秒后自动在默认浏览器打开，期间可取消、复制或立即跳转。
  多个二维码需先选择一个；非网址内容可复制。
- **快速聊天**：右键打开输入气泡，回车发送消息；关闭后保留未发送的草稿。

右键桌宠打开菜单：**一二菜单**（📅 待办 / 🔁 固定任务 / 📊 使用统计 / 👤 账号）、
**显示/关闭待办气泡**、**聊天**、**快速聊天**、**聊天记录**、**扫描二维码 (Alt+Q)**、**退出**。

## 配置（可选）

默认零配置即可运行。要改服务器地址、角色名或身份时，可在项目根目录新建 `config.json`，
例如 `{"ws_url": "ws://192.168.1.5:8765"}`；也可以使用下方命令行参数。

| 键 | 说明 | 默认 |
|---|---|---|
| `pet_name` | 角色名，决定 `res/<名字>/` 与数据文件位置 | `yier` |
| `identity` | 本机身份（yier / bubu），决定用哪套角色资源与显示名 | `yier` |
| `peer` | 聊天对象，账号模式下只用于显示；不填则按身份推导 | 推导 |
| `ws_url` | 服务器地址，支持 `ws://` 与 `wss://` | `ws://localhost:8765` |
| `token` | 账号模式之前的共享密钥，**现在不再参与连接**，保留只为老配置能读 | `""` |

账号相关的键（`uid` / `phone` / `nickname` / `pass_token` / `peers`）由登录流程自己维护，不用手填：
登录成功后桌宠把这五项写回 `config.json`，下次打开自动登录。**密码从来不落盘**，存下来的是服务器发的通行证。

**配置坏了不会静默降级**：`config.json` 是非法 JSON 时，启动会打印路径与原因并以退出码 2 结束；
键名拼错只往 stderr 打一行 warning 并忽略该键。

`config.json` 不会进版本库（里面可能有通行证），不要提交或公开其内容。

## 账号与聊天

聊天需要一台运行 **v2 WebSocket 服务器**的机器（转发消息 + 存历史；服务器在另一个仓库 `YierBubu`
的 `server/ws_server.py`，只有它需要额外装 `websockets`）。**没有服务器时桌宠照常运行**，
只在后台每 5 秒重试连接。

用法四步：

1. 右键桌宠 → 一二菜单 → **👤 账号** → 用手机号 + 密码注册（或登录）
2. 把页面上的**我的连接码**（形如 `bubu-a7Kd29`，**区分大小写**）发给对方
3. 对方在他的账号页填这串码，申请连接
4. 你的账号页会出现「待你确认的申请」，点「同意」就连上了

拿到连接码的人只能给你发一条申请，必须你点同意才算数；同意之前对方看不到你的手机号，也看不到历史。
申请 24 小时过期，同一天被拒满 5 次会锁到第二天。

> 这套要求服务器也是 v2。旧服务器配新桌宠会握手失败，原因会打在 stderr（`[ws] ...`），不会静默降级。

## 命令行参数

```powershell
python main.py --server ws://192.168.1.5:8765   # 换服务器
python main.py --pet-name bubu                  # 换角色（决定 res/<名字>/ 与数据文件位置）
python main.py --identity bubu                  # 换本机身份
python main.py --config other.json              # 换配置文件
```

配置优先级：**命令行 > `config.json` > 代码内置默认值**。

## 数据都在本地

`res/<pet_name>/` 下三个文件：`tasks.json`（待办）、`fixed_tasks.json`（固定任务规则）、
`usage.json`（陪伴时长）。第一次用到时自动生成，都已在 `.gitignore` 里，不会提交进仓库。
